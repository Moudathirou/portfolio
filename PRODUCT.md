## Product Principles
1. Prouver plutôt qu'affirmer : montrer le mécanisme (sources, citations, mesures) au lieu d'adjectifs.
2. Vérité stricte : chaque phrase correspond à une ligne du CV ; le secteur réel de chaque expérience est affiché.
3. De bout en bout : chaque offre se termine en production, avec coûts et qualité mesurés.
4. Confidentialité assumée : expliquer pourquoi le code n'est pas montré, c'est un argument pour les clients santé.
